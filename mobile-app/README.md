# Mobile Application

## Purpose

The mobile application provides real-time environmental monitoring
information and alerts.

## Main Features

- Live node status
- Flood alerts
- Fire alerts
- Air-quality alerts
- Landslide alerts
- GPS-based location
- Risk levels
- Historical events
- Sensor summaries
- Notifications

## Main Screens

### Dashboard

Displays:

- Total nodes
- Active alerts
- Normal nodes
- High-risk nodes

### Node Details

Displays:

- Node ID
- Hazard type
- Sensor readings
- GPS location
- Risk level
- Last update

### Alerts

Displays:

- Hazard
- Location
- Time
- Risk
- Recommended action
